# ERP-Java-MVC

Sistema ERP desenvolvido como atividade prática para estudo e aplicação
dos fundamentos de desenvolvimento em Java.

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema de gerenciamento
empresarial utilizando os conhecimentos adquiridos em Java.

A aplicação será desenvolvida como um sistema desktop executado
localmente, utilizando Java Swing para a interface gráfica, o padrão
arquitetural MVC para organização do código e MySQL para persistência
dos dados.

## 🎯 Objetivos

- Praticar programação orientada a objetos em Java;
- Aplicar o padrão MVC;
- Desenvolver interfaces gráficas com Java Swing;
- Trabalhar com banco de dados MySQL;
- Implementar operações de persistência de dados;
- Desenvolver um sistema de forma colaborativa;
- Preparar a equipe para projetos de maior complexidade.

## 🏗️ Arquitetura

O projeto utiliza uma organização baseada no padrão MVC:

Model
  ↓
Dados e regras relacionadas às entidades

View
  ↓
Interface gráfica desenvolvida com Java Swing

Controller
  ↓
Intermediação entre a interface e as regras da aplicação
